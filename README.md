# 译码 CodeLens · 把代码翻译成人话

一个帮助**零基础**用户看懂代码的本地网页应用。在右侧粘贴任何代码，左侧立即给出
整体概览（这段代码是干什么的）、逐行讲解（每一行在说什么）、关键术语（陌生概念一看就懂）。
**下方还有实时预览**：HTML/CSS 直接渲染成网页画面，Python/PHP/C/C++ 在浏览器里真实运行并显示输出。

## 支持的语言

Python · PHP · HTML · CSS · C 语言 · C++

## 实时预览（无需任何后端）

| 语言 | 预览方式 |
| --- | --- |
| HTML | 网页画面**实时渲染**（改代码立刻看到页面） |
| CSS | 样式实时套用在示例页面上展示效果 |
| Python / PHP / C / C++ | 内置**本地迷你解释器**真实运行，显示 print / echo / printf / cout 的输出 |

- 代码变化自动运行（可关闭「实时运行」开关），死循环有**步数保护**，不会卡死页面
- 程序需要输入时（`input()` / `scanf` / `cin`），先在预览栏的「程序输入」框里填好（每行一个），再点 ▶ 运行
- 运行报错会用**通俗中文**提示，并指出出错行
- 教学子集说明：本地解释器覆盖常见教学语法；个别高级语法（如导入外部库）会给出中文提示

## 使用方式

1. 双击打开 `index.html`（推荐 Chrome / Edge 浏览器）；或双击 `start.bat` 通过本地服务器访问（可选）。
2. 右上角选择语言 → 点「示例代码」或直接在右侧输入/粘贴代码。
3. 左侧释义面板自动生成解释；点任意讲解条目，右侧代码会高亮定位到对应行。
4. 左右区域之间的分隔条可以拖动，默认比例为**释义 4 : 代码 6**。
5. 预览栏的「▾」可收起/展开预览。

### 手机访问（手机浏览器打开）

1. 电脑上双击 `start.bat` 启动本地服务器（保持窗口开着）。
2. 手机和电脑连**同一个 WiFi**。
3. 手机浏览器访问：`http://电脑的IP地址:8080`（电脑 IP 可在 cmd 里输入 `ipconfig` 查看，如 `192.168.1.100`）。

手机上会自动切换为**竖屏上下布局**（代码+预览在上、释义在下）；横屏或电脑上自动用**左右分栏布局**。全部功能（释义、解释器运行、HTML/CSS 预览）在手机上同样可用。

## 释义引擎

- **内置离线引擎（默认）**：本地词法分析 + 语法规则，无需联网、无需任何 Key，开箱即用。
- **AI 增强（可选）**：点击右上角「AI 增强」→ 齿轮设置，填写任意 OpenAI 兼容接口的 Base URL、
  API Key 与模型名（DeepSeek / Kimi / 通义 / 智谱 / 本地 Ollama 均可）。
  开启后释义由大模型生成，讲解更口语化；请求失败时自动回退到内置引擎，不影响使用。
  Key 仅保存在本机浏览器 localStorage 中，不会上传到任何服务器。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl + Enter` | 立即解释（强制刷新） |
| `Tab` | 在代码框中插入 4 个空格缩进 |

## 目录结构

```
codelens/
├── index.html        # 页面骨架（左右 6:4 布局 + 底部预览）
├── start.bat         # 可选：本地服务器启动脚本
├── css/style.css     # 玻璃拟态视觉样式
└── js/
    ├── highlight.js      # 多语言词法分析与语法高亮
    ├── engine.js         # 离线释义引擎（概览/逐行/术语）
    ├── samples.js        # 六种语言的示例代码
    ├── ai.js             # AI 增强模块（OpenAI 兼容接口）
    ├── interp-common.js  # 迷你解释器公共框架（步数保护/输入/输出）
    ├── interp-python.js  # Python 迷你解释器
    ├── interp-c.js       # C / C++ 迷你解释器
    ├── interp-php.js     # PHP 迷你解释器
    ├── preview.js        # 实时预览逻辑（iframe 渲染 + 运行控制台）
    └── app.js            # 主逻辑（拖拽分栏、联动、交互）
```

纯 HTML/CSS/JS 实现，无任何外部依赖，可完全离线运行。
